## 3. 核心题评分契约（三题，一次一问用）

### 契约 C1：PDF 高亮实现

```yaml
question_id: fna-highlight-01
claim_id: C1
question: 你简历上写「基于 PDF 文本层坐标实现字段级精准高亮，四级降级链」，这个高亮具体是怎么实现的？为什么匹配要分四级？
intent: 验证个人主导 claim 的实现深度（能否手推算法）与取舍依据
required_evidence:
  - 文本层坐标来源（getTextContent 的 transform 矩阵 → 页面坐标）与行聚类成矩形
  - 坐标百分比化 → 与缩放/旋转解耦的原因
  - 四级各自对付什么失败形态（精确 → 紧凑 → 跨空白正则 → 分词容错）+ 每级打分选最优
  - 个人边界：哪些是我写的、为什么不用现成查看器（鉴权头 + 字段级扩展点）
followup_triggers:
  - 只说「用了 pdf.js」没有数据流 → 追坐标计算链路
  - 四级说不清各自场景 → 给一个具体失败样例（AI 值与原件空格切分不一致）让其归级
  - 说不清为什么不用现成组件 → 反事实：如果允许 iframe embed 会缺什么
stop_condition: 必要证据齐 + 至多一个反事实追问（例：旋转 90° 的 PDF 高亮错位怎么排查）
参考锚点: 面经 Q4/Q4a/Q4b（150+ 字口播已备）
```

### 契约 C2：数据驱动状态机

```yaml
question_id: fna-statemachine-01
claim_id: C2
question: 你们工作台的审批流是「数据驱动状态机」，这是什么意思？为什么不用现成的工作流引擎？
intent: 验证架构理解深度 + 个人边界（参与开发 ≠ 设计者，防冒领）
required_evidence:
  - 表驱动机制：流转定义存表（from/action/to/角色/守卫），引擎只做查表+守卫+单事务落库
  - 「加环节不改代码只插配置」的具体含义
  - 不用工作流引擎的取舍：守卫指令集 ≤3 种，小解释器够用；膨胀才是换引擎信号
  - 边界诚实：引擎为团队既有，本人参与开发/集成并完整理解（不答「我设计的」）
followup_triggers:
  - 说不清守卫怎么工作 → 追三种守卫各防什么（角色白名单/必查全标/自审拦截）
  - 冒领设计 → 划界：「状态机引擎是你设计的吗」— 答：团队设计，我参与开发并能把 492 行引擎逐段讲清
  - 只讲 happy path → 追失败：对已过账的票再提交会发生什么（409 查表无合法转移）
stop_condition: 必要证据齐 + 至多一个追问（幂等两层防重 或 Retry 断链活例）
参考锚点: 面经 Q1/Q1a/Q1b/Q1c + Q5a（乐观锁缺口主动讲）
```

### 契约 C3：双轨鉴权内省

```yaml
question_id: fna-auth-01
claim_id: C3
question: 简历写「Microsoft SSO 令牌无法本地验签，走内省模式」——为什么无法本地验签？内省为什么是安全的？
intent: 验证鉴权机制理解 + 安全推理（「先证通道可信再读数据」）
required_evidence:
  - 为什么不能本地验签：微软只公开 ID token 公钥，Graph access token 拿不到验签公钥
  - 内省链路：携 token 调官方 /me → 200 = 权威方承认令牌 → 从未验签 payload 读声明
  - 安全推理：伪造令牌内省直接失败；代价（网络往返）→ 进程内缓存按 exp 淘汰对冲
  - 权能模型一句话：「身份是动作上下文」——同一账号 submit 时是制单角色、approve 时是复核角色
followup_triggers:
  - 只说「调接口验证」没有为什么安全 → 追「万一那个接口返回被伪造呢」
  - 说不清权能模型 → 追「双权能账号同一张票既提交又审批行不行」（自审禁令）
  - 边界模糊 → 划界：参与集成联调，非鉴权体系设计者
stop_condition: 必要证据齐 + 至多一个追问（刷新时序竞争：为什么安全拦截放路由守卫不在注入时刻）
参考锚点: 面经 Q2/Q2a/Q2c
```

**在家自练方法（推荐顺序）**：
1. **先答后看**：遮住面经答案，对 §3 三道核心题各口述 90 秒录音；
2. **对照评分**：回放录音，逐条对 `required_evidence` 打勾——缺哪项就回到面经对应 Q 的口播重读；
3. **变体自测**：把追问树每层当独立题再答一遍（答案不是背原文而是换自己的话）；
4. **边界预演**：C2/C3 必练「这是你设计的吗」的标准划界话术（参与开发 + 完整理解 + 能逐段讲清，不冒领）；
5. **下次会话陪练**：对我说「继续 F&A 面试 grill」即从契约 C1 第一题开始一次一问互动验证，答完出真掌握度报告（verified/partial/unverified 状态 + 复练队列）。
