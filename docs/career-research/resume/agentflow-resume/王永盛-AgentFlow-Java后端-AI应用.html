并发编排模型（引擎核心）
  • 问题：多 Agent 并行写共享上下文，锁竞争与顺序不确定。机制：YAML 声明 DAG 经最长路径预分层，同层节点 Virtual Threads 并行 + 只读快照互不可见，屏障后按声明序确定性归并——免锁并发；在 BSP 不变量上扩展运行时条件路由（谓词 + 可达性剪枝）与有界循环（回边 + 迭代轮次），路由决策落 checkpoint 供恢复重放。
  • 结果：同层零锁零竞态、跨层语义确定，多拓扑 demo（串行链 / 双层 fork-join / 路由 / 反思循环）全部断言通过；「动态路由牺牲确定性、checkpoint 重放买回来」一句话讲清 trade-off。
崩溃恢复机制（正确性硬功）
  • 问题：长任务崩溃后整段重跑 = LLM 重复计费。机制：节点完成即持久化输出（部分提交防重复计费）+ 屏障为逻辑提交点定恢复边界；写入幂等条件 upsert + 迟到写入防护。边界：恢复触发层（生产调度器）为已知边界，如实答。
  • 结果：修复两个被 4 个独立评审视角确认的正确性缺陷（崩溃层输出丢失 / 迟到完成防护缺失）；真 PostgreSQL 集成测试实跑验证；崩溃 / 审批 / 循环三条恢复路径共用同一套重放续跑骨架。
