# Schematic Discipline — 图纸纪律

一张架构图应当像一张工程制图：信息密度由耐心积累而来，而不是由装饰堆砌而来。Schematic Discipline 的信条是**把不可见的执行过程当作可观测的现象来记录**——super-step 的同步屏障、两层 checkpoint 的落盘时刻、并发节点的扇出扇入，全部以系统化观测的语言呈现：精密的网格底纹、重复累积的刻度标记、分层的参考线系统。观者第一眼看到的是一张严谨的图纸，细看才发现它描绘的是一次并发的呼吸。每一根线、每一个刻度、每一处对齐，都出自顶端从业者的手笔，是无数小时反复校准的产物——不精确、不对齐、不呼吸的地方不存在。

**空间与形式**：构图采用严格的横向三泳道（API 层 / 编排层 / 执行层），泳道由极细的参考线分隔而非色块包围。箭头是唯一的叙事主角——它们携带标签（YAML DSL / SHA-256 Auth / Plan→Execute→Barrier），在空间中划出确定性路径。左列自上而下的编译链（Parser → Definition → Layerer → Checkpoint）与右侧 BSP 时间轴形成「静态结构 vs 动态过程」的空间对仗：左窄右宽，左密右疏，静与动的张力在黄金分割处交汇。所有元素以 8px 基线网格落位，精确到令人不安的程度——这正是图纸纪律的要求。

**色彩与材质**：克制到近乎苛刻的双色系统——深蓝墨（Indigo Ink）承担结构与权威，暖琥珀（Amber）只出现在「同步屏障 barrier」这一语义焦点上，其余一律让位于纸白与 4% 灰的细线。色彩即语义：琥珀色越少，屏障越醒目。背景是极浅的工程方格纸纹理，密度低于任何前景元素，只为建立「这是一张被反复推敲过的图纸」的物证感。没有渐变，没有阴影堆叠——只有线的粗细层级（0.75 / 1.5 / 3px）承担全部深度。

**尺度与节奏**：三种字号层级严格分工——等宽小写标签（11px）做系统注脚，组件名（17px）做节点标识，唯一的标题（42px）以薄字重压住全局。节奏由重复创造：super-step 0 的三个并行节点 A/B/C 用完全等距、完全同形的卡片，Super-step 1 的聚合节点用等宽但更高的单卡——同一模数的变奏，如同乐句的重复与终止。左侧编译链四个节点的行距与右侧时间轴的行距刻意取同一数值，让两条视觉流以同一心跳行进。

**构图与平衡**：非对称的均衡。左侧 35% 是垂直下落的静态编译链，右侧 65% 是水平展开的动态时间轴；两者在底部由 WorkflowContext（channel 快照）收束为一个共同的终点——这是全图唯一的汇聚点，也是视觉重量最重的地方。标题压在左上角大片留白处，右下角以一枚极小的图纸角标（图号 / 版本）收尾，形成对角线张力。所有文字与图形绝不溢出画布边界，所有间距不小于最小呼吸单元。

**视觉层级**：先看箭头主干（3px），再看组件节点（1.5px 描边），然后是注脚标签（0.75px 细线连接），最后是背景网格（4% 灰）。四层深度，每层只对上一层的细节做奖励式补充。信息不在段落里，在线的走向里、在卡片的间距里、在琥珀色出现的唯一位置里——懂得 BSP 的人会在屏障线前停下，不懂得的人只会觉得：这是一张被苦心经营过的图纸。

---

*主题的隐性基因：这张图描绘的正是 BSP（Bulk Synchronous Parallel）模型——super-step 内的并发自由、barrier 处的全局同步、两级 checkpoint 在屏障两侧的落盘。熟悉并行计算的人会在等距卡片与琥珀屏障线之间认出它；不熟悉的人看到的是一张严谨的工程图纸。引用不宣布自己，懂的人自然会心。*
